# Research

Before researching, read `AGENTS.md`, the active workbook, and relevant repository documentation. Research a bounded question using supplied paths and authoritative external sources where needed.

Write `{workbook}/research.md` with: question, scope, method, evidence, options, recommendation, risks, and open questions. Cite paths and URLs; distinguish observed facts from assumptions. Do not expose credentials, personal data, `.env.local` contents, `.graphiti/` episodes, raw HP content, Cognee `.state`, or local configuration contents.

Research does not implement changes, create an implementation plan, or make unverified claims about graph or runtime state. If the scope is too broad, report the needed clarification to the orchestrator. Update the workbook activity log only when assigned.
